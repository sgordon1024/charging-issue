Case study: second alternator stopped charging — failed temperature sensor

2024 Entegra Launch (Sprinter 907/OM654) · Nations 48V engine generator + Wakespeed WS500 (fw AREG2.5.2) · Lithionics 51V · Victron Cerbo GX · Resolved August 09, 2026
Resolution: WS500 fault 42 ("required sensor missing") — the alternator temperature sensor had failed open. One replacement thermistor (single bolt + green 2-pin connector) and a clean ignition cycle restored full charging: 4.4 kW confirmed on the next drive.
Root cause — an unmounted sensor in the hottest airspace of the van.

On removal, the failed sensor was found zip-tied loose behind the alternator — never bolted to it. That placement is a double defect: the epoxy-potted thermistor dangled on its own leads in the alternator's exhaust heat, free to vibrate with the diesel, so every multi-hour 4-5 kW charging session (this van logged several in 90-100°F conditions the week before failure) baked the element while vibration worked the leads and crimp. The failure signature matches exactly: one day of choppy charging as a fracturing joint made and broke contact, then permanently open.

The same placement also quietly compromised thermal protection the whole time: reading air instead of case temperature, it under-reported — so the WS500 would have derated later (or never) while the alternator ran hot. Correct mounting per the install guide: the sensor's ring lug bolts to the alternator body/bracket — the sensor is supposed to run hot with the machine it protects. A useful QA check for other installs of this kit: confirm the temp sensor is actually bolted, not tied off in the harness.

What each system showed while it was broken

Victron Cerbo GXAlternator tile disappeared entirely (a faulted WS500 stops announcing on CAN). Battery showed zero charge current on drives.
Lithionics appCAN Charger Status E103 — the BMS broadcasting its 57.6 V / 165 A request and logging that nothing answered. No battery faults; charging permitted.
Firefly / dashNothing. No warning of any kind — the chassis system is independent, so the failure is invisible while driving.
WS500 LEDSlow green (idle) at first glance; red blink pattern under fault. We counted 4-4 from video; the serial said 42 — count carefully or trust serial.
WS500 USB serialFLT;,42 ('required sensor missing') and the alternator-temp field at -99 — the two lines that solved the case.

The 10-minute diagnostic path (what we'd tell the next owner)

1Plug into the WS500's USB port and read the stream (115200 baud; any serial terminal). A FLT line + '-99' in the AST temp field = temp sensor circuit. Ten minutes, no wrenches.
2Temp field -99? Unplug the green connector at the alternator and ohm the sensor pigtail: ~5-15 kOhm = healthy, OL = failed sensor. (Pin-to-pin — one pin to the case reads open by design on this two-wire sensor.)
3Sensor OL: replace it (ring-terminal thermistor, one bolt + the green 2-pin). Owner-serviceable. BOLT the ring lug to the alternator body/bracket — ours was found zip-tied loose behind the alternator, which both caused the fatigue failure and defeated thermal protection. Do not mount it "for airflow."
4After ANY harness unplugging during diagnosis, complete one full clean ignition cycle before judging the result — we saw 0 A on a first post-repair idle test that healed itself on the next proper drive.
5Verify: fault lines gone, temp reads ambient, and on the next drive the Cerbo Alternator tile returns with real amps. Ours came back at 4.4 kW.

Dead ends we chased — so you don't have to

Battery resetMade no difference — the Lithionics was healthy throughout (cells balanced, charging permitted, contactor closed). Its E103 was a symptom, not a cause.
Chassis fuse panelsAll live. The two dead seat-base fuses (19/20) are the rear-window defroster — normally unpowered. Don't chase them.
Voltage senses / inline fusesAll measured good. The 52-53 V readings at the alternator stud simply mirror battery voltage — they neither clear nor convict the alternator.
Feature-in (white wire) at 0 VMeasured dead with engine running during diagnosis — yet the system later charged perfectly with it unchanged. In this CAN-managed Lithionics config the enable evidently doesn't require that line high; don't chase it first.
LED blink countingWe decoded 4-4 from a slow-motion video; the serial fault register said 42. The USB dump is authoritative.
